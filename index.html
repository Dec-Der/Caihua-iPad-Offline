离线标注 · 使用与数据安全

① 请通过 HTTPS 安装到 iPad 主屏幕，首次联网打开后确认右上角显示“离线已就绪”。
② 建议 Mac 网页导入照片后点击「Mac 上传云端」，iPad 联网登录同一云账号后自动下载；下载完成可断网绘制，也保留手动导入照片与 ZIP 的功能。
③ Apple Pencil 画裂隙，压力映射 1–45 原图像素；手指移动画面，双指缩放。每笔画结束立即保存到本机。
④ 导出训练文件可点“生成 Masks＋Overlays＋JSON ZIP”，小批处理后保存并核验各包；每完成 5–10 张，仍须先点“生成标注备份 ZIP”，再点“保存 / 分享备份”通过系统分享保存到“文件”或 AirDrop 给 Mac。**只有完成导出和异地备份，数据才算真正安全。**
⑤ 不要清除 Safari 网站数据，不要卸载主屏幕应用，也不要在多个不同浏览器之间切换使用。

照片可在你授权后上传到私有云存储；不上传到 GitHub Pages。笔画 JSON 默认只在 iPad 本地，不会自动上传云端。返回 Mac 后使用包内导入工具，把 JSON 写入新建的项目。原图仍应保留 Mac 原件。

目前实现：Brush、撤销、重做、整笔删除、手动确认无裂隙、图片列表、离线存储及 ZIP 备份；不是原平台的全部编辑器功能（暂不包括 Polygon、SAM、Box）。

☁ 云照片库（无需 AirDrop）

Mac 网页导入照片 → 「Mac 上传云端」 → iPad 用同一账号登录，联网时自动下载照片到本机 → 断网照常画。照片存放在你自己创建的 Supabase 私有存储桶，标注只保存在本机，仍需定期备份 ZIP。

第一次配置：在 Supabase 创建私有 bucket caihua-photos 并设置登录权限。此处只能填写 Project URL 和 publishable/anon 公钥，绝不能填写 secret/service_role 密钥。Mac 和 iPad 各配置一次。
