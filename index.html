V3.0 · 三步操作

① 在 Mac 使用 mac.html 上传原尺寸照片，不经过 Mac 浏览器本地相册。② iPad 登录一次后，手动点击“同步云端照片”，下载完成后断网即可画。③ Apple Pencil 的 1–45 px 压感、平滑笔触和红色显示保持原版不变。④ 每笔抬起后等待显示保存成功，点击“生成 JSON 备份 ZIP”分包保存（每包最多10张）。只在 Mac 后续生成 PNG。⑤ 不能同时打开两个 iPad 标注标签页；不要清除本站数据。数据同步不是标注同步，务必把 JSON ZIP 保存到 iCloud Drive。

目前实现：Brush、撤销、重做、整笔删除、手动确认无裂隙、图片列表、离线存储及 ZIP 备份；不是原平台的全部编辑器功能（暂不包括 Polygon、SAM、Box）。

☁ 云照片库（无需 AirDrop）

Mac 独立上传页上传照片 → iPad 用同一账号登录，点击同步按钮下载照片到本机 → 断网照常画。照片存放在你自己创建的 Supabase 私有存储桶，标注只保存在本机，仍需定期备份 ZIP。

第一次配置：在 Supabase 创建私有 bucket caihua-photos 并设置登录权限。此处只能填写 Project URL 和 publishable/anon 公钥，绝不能填写 secret/service_role 密钥。Mac 和 iPad 各配置一次。

删除所选图片的 iPad 本机照片、标注和云端原图，不能撤销。已导出的 ZIP 不受影响。请先保留 Mac 原图：JSON ZIP 不包含原照片。

选择已保存的 JSON 备份 ZIP（可选多个分包），核验后勾选要删除的图片。旧版本导出的 V3.0 分包也可核验。核对云端原图会产生少量下载流量；清理时请保持此页在前台，并关闭其他标注标签页。
