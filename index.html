离线标注 · 使用与数据安全

① 请通过 HTTPS 安装到 iPad 主屏幕，首次联网打开后确认右上角显示“离线已就绪”。
② 原照片通过 AirDrop 保存到 iPad“文件”，在这里选择多张导入；也可导入 Mac 制作的分批照片 ZIP。
③ Apple Pencil 画裂隙，压力映射 1–45 原图像素；手指移动画面，双指缩放。每笔画结束立即保存到本机。
④ 每完成 5–10 张，先点“生成标注备份 ZIP”，再点“保存 / 分享备份”通过系统分享保存到“文件”或 AirDrop 给 Mac。**只有完成导出和异地备份，数据才算真正安全。**
⑤ 不要清除 Safari 网站数据，不要卸载主屏幕应用，也不要在多个不同浏览器之间切换使用。

本离线入口只保存在 iPad，不把你的照片或标注上传至 GitHub Pages。返回 Mac 后使用包内导入工具，把 JSON 写入新建的项目。原图仍应保留 Mac 原件。

目前实现：Brush、撤销、重做、整笔删除、手动确认无裂隙、图片列表、离线存储及 ZIP 备份；不是原平台的全部编辑器功能（暂不包括 Polygon、SAM、Box）。
